# 🏏 IPL Performance Analytics Dashboard

A Power BI (`.pbix`) dashboard that analyzes historical IPL (Indian Premier League) match and delivery data — showcasing team performance, player statistics, match outcomes, venue trends, and season-wise patterns through interactive visuals.

## 🎯 Objective

To analyze IPL historical data and uncover insights into team performance, player statistics, match outcomes, venue trends, and season-wise patterns using interactive Power BI dashboards.

## 🛠️ Tech Stack

| Component | Detail |
|---|---|
| **Data Source** | IPL Matches & Deliveries Dataset |
| **Tool** | Power BI |
| **Tech Used** | Power Query, DAX, Data Modeling, Interactive Visualizations |

## 📄 Report Pages

The dashboard consists of **6 pages** in total:

1. **Objective** — Introductory page covering the project's goal, data source, and tech stack.
2. **Overview** — High-level KPIs: Total Matches, First/Last Season, Total Runs, Fours, Sixes, Boundaries, Dot Balls, Extra Runs, Total Wickets, Average Strike Rate, Economy — plus a city-wise matches treemap.
3. **Teamwise Analysis** — Team-wise Total Wins, Total Runs (by batting team), Total Wickets (by bowling team), and Total Titles (pie chart).
4. **Batting Performance** — Player-wise batting stats: Total Runs, Sixes, Boundaries, Strike Rate, and a Player of the Match/Target Runs treemap.
5. **Bowling Performance** — Bowler-wise Economy, Dot Balls, Total Overs/Balls (waterfall chart), and Bowler Wickets (funnel chart).
6. **Conclusion** — An insights summary covering key findings across all pages:
   - 📊 Tournament Overview & Season Trends
   - 🏏 Batting Performance Analysis
   - 🎯 Bowling Performance Analysis
   - 👥 Team Performance Comparison
   - 🏟️ Venue & City-wise Analysis
   - 👤 Player Performance & Rankings

## 📊 Key Metrics Covered

- Total Matches, First Season, Last Season
- Total Runs, Fours, Sixes, Boundaries
- Dot Balls, Extra Runs, Total Wickets
- Average Strike Rate, Economy
- Team-wise Wins, Titles
- Batter-wise Runs, Sixes, Boundaries, Strike Rate
- Bowler-wise Economy, Overs, Balls, Wickets, Dot Balls
- City / Venue-wise match distribution

## ▶️ How to Use

1. Install Power BI Desktop (free download from the [Microsoft website](https://powerbi.microsoft.com/desktop/) if you don't have it).
2. Open the `IPL_Cricket_Analysis.pbix` file in Power BI Desktop.
3. Use the page navigation on the left to explore the pages in sequence: Objective → Overview → Teamwise Analysis → Batting Performance → Bowling Performance → Conclusion.
4. Use the slicers and filters to drill down into season-, team-, or player-specific views.
